사용법
1. 코드를 다 다운받는다.
2. 디스코드 봇을 만들어 어드민을 주고 자신의 개인서버에 초대한다.
3. .env파일을 만든다 내용은
4.  # 디스코드 봇 토큰
    DISCORD_TOKEN=

    # 구글 제미나이 API 키
    GEMINI_API_KEY=
    
6. 모든파일과 위의 만든 .env파일이 있는지 하나의 폴더에 있는지 확인한다
7. 메인파이를 실행한다
8. 잘 돌아가면 이걸 로컬로 돌리던지 개인서버를 구축했다면 거기서 돌려도 된다(주인장은 개인오라클 서버팜)
9. 기본적으로 봇은 켜져있으니 사용안할시엔 !off로 끄고 쓰고싶다면 !on으로 키면된다
10. !준비 이후 !로어+텍스트파일을 넣는다 혹은 !로어 이후에 장르만적어도 된다. 만약 개인적으로 룰을 쓰고 싶다면 !룰 +텍스트파일 삽입하면된다. 
11. 다시 !준비로 준비가 되었는지 확인하고 !가면 이름 이후 !설명 내용 으로 준비한다
12. !시작이후 즐긴다.

다인플레이 적용은 했는데 되는지는테스트 안해봄
