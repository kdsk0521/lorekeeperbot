## 4. 턴당 비용 계산

### Flash (Call 1 + 3 + 4 + 발효 상각)

| | 입력 토큰 | 출력 토큰 |
|-|-----------|-----------|
| Theoria | 23,850 | 2,000 |
| Physical | 1,300 | 85 |
| Batch | 1,505 | 433 |
| 발효 상각 (÷25) | 180 | 6 |
| **소계** | **26,835** | **2,524** |

```
Flash 입력: 26,835 × $0.50 / 1,000,000 = $0.01342
Flash 출력:  2,524 × $3.00 / 1,000,000 = $0.00757
─────────────────────────────────────────────────
Flash 턴당 합계                         = $0.02099
```

### Pro (Call 2)

```
Pro 입력: 36,525 × $2.00 / 1,000,000 = $0.07305
Pro 출력:  1,460 × $12.00 / 1,000,000 = $0.01752
─────────────────────────────────────────────────
Pro 턴당 합계                          = $0.09057
```

### 턴당 총합

```
$0.02099 (Flash) + $0.09057 (Pro) = $0.11156 / turn
                                   ≈ ₩162 / turn (환율 ₩1,450)
```

## 10. 계산 공식 (재계산용)

```
턴당_비용 = (Flash입력토큰 × Flash입력단가) + (Flash출력토큰 × Flash출력단가)
          + (Pro입력토큰 × Pro입력단가) + (Pro출력토큰 × Pro출력단가)
          + (발효비용 / 25) + (DEEP비용 / 200)

N턴_비용 = 턴당_비용 × N

Flash입력토큰 = Theoria시스템(16,200) + Theoria유저(7,650) + Physical(1,300) + Batch(1,505)
Flash출력토큰 = DAI(2,000) + Physical(85) + Batch(433)

Pro입력토큰 = 정적슬롯(13,200) + PC(430) + NPC_슬롯7(NPC수에_따라) + 로어_슬롯8(용량에_따라)
            + 발효(600) + DAI아이스버그+수법피드백(1,210) + NPC리마인더(350) + 텔레스코프v4슬롯(935)
            + 히스토리(4,200) + 트레이닝(500) + 사용자입력(200)
Pro출력토큰 = 텔레스코프v4(600, 실측~2100자) + 서사(710) + 태그오버헤드(150)

NPC_슬롯7 ≈ (선택NPC수 × 장면별섹션~6500자/3.5) + (나머지NPC × 80/3.5) + (선택NPC × 보이스카드300/3.5)
            장면별섹션 = scene_type에 따라 Core+필요섹션만 선택, 캡 없이 원문 보존 (안전캡 15000자)
로어_슬롯8 ≈ 선택청크수 × 평균청크크기 / 3.5
```

## 참고

- **토큰 환산**: 한영 혼합 텍스트 ~3.5자/토큰 (보수적)
- **환율**: ₩1,450/USD (2026-02 기준, 변동 있음)
- **프롬프트 ≤200K**: 현재 Pro 입력은 ~37K로 200K 미만 → 낮은 단가 적용
- **Context Caching**: Gemini 캐시 사용 시 정적 슬롯(~13,000토큰) 재전송 비용 절감 가능
- **사고 토큰**: Gemini 3.1 Pro의 사고(thinking) 기능 활성화 시 출력 토큰 대폭 증가 가능 — 현재 비활성 가정
