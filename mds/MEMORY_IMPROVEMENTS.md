# AI 메모리 개선 사항 (AI Memory Improvements)

## 문제점 (Problem)
AI가 이전 대화 내용을 잘 기억하지 못하고 맥락을 잃는 문제가 있었습니다.

## 해결 방법 (Solution)

### 1. 대화 기록 보존 기간 증가
- **FRESH 임계값**: 40개 → **80개** 메시지
  - 더 많은 최근 대화를 원본 그대로 보존
  - 발효(압축)가 너무 빨리 일어나지 않도록 조정
  
- **발효 청크 크기**: 20개 → **30개** 메시지
  - 한 번에 더 많은 메시지를 요약하여 맥락 손실 감소
  
- **FERMENTED 임계값**: 5개 → **8개** 요약
  - 중기 기억을 더 오래 유지

### 2. AI 컨텍스트 윈도우 확대
- **최근 히스토리**: 10개 → **20개** 메시지
  - AI가 참조하는 직전 대화 범위 2배 증가
  
- **Immediate 컨텍스트**: 20개 → **30개** 메시지
  - 발효 시스템의 즉시 기억 범위 증가

### 3. 메모리 강조 및 명확한 지시사항
- Fermented 섹션에 **CRITICAL 경고** 추가
- Deep Memory 섹션에 **필수 참조** 표시
- AI에게 응답 생성 전 메모리 체크 지시사항 추가:
  1. ✅ Fermented 섹션에서 관련 과거 사건 확인
  2. ✅ 현재 응답이 기존 히스토리와 모순되지 않는지 검증
  3. ✅ 과거 NPC, 장소, 사건 참조
  4. ✅ Deep Memory 및 Episode Summary와 일관성 유지

## 효과 (Expected Results)
1. **더 긴 대화 기억**: 80개 메시지까지 원본 보존
2. **더 나은 맥락 이해**: 20개 최근 메시지 참조
3. **일관성 향상**: 명확한 메모리 참조 지시
4. **스토리 연속성**: 발효된 기억도 강력하게 강조

## 기술적 세부사항 (Technical Details)

### 변경된 파일
- `fermentation.py`: 임계값, 컨텍스트 빌드 함수
- `main.py`: AI 프롬프트, 히스토리 참조 범위

### 메모리 계층 구조
```
DEEP MEMORY (초장기)
    ↑ 압축 (8개 초과 시)
FERMENTED (중기) - 최대 8개 요약
    ↑ 발효 (80개 초과 시)
FRESH (단기) - 최대 80개 원본
    ↑ 최근 20개 AI 참조
IMMEDIATE (즉시) - 최근 30개 표시
```

### 토큰 효율성
- 불필요하게 빠른 압축 방지
- 중요한 맥락은 더 오래 유지
- 발효 시 더 많은 내용을 한 번에 요약하여 품질 향상

## 사용자 액션 (User Actions)
별도의 액션 필요 없음. 업데이트 후 자동으로 적용됩니다.

기존 세션의 경우:
- 새로운 임계값이 자동으로 적용됩니다
- 이미 발효된 메모리는 그대로 유지됩니다
- 앞으로 더 많은 대화가 보존됩니다
