# 로어북 & NPC 작성 가이드

---

## 1. 로어북 (`!로어`)

### 입력 방법

| 방법 | 동작 |
|---|---|
| `!로어 [텍스트]` | 기존 로어에 **누적** (append) |
| `!로어` + 파일 첨부 | 기존 로어 **덮어쓰기** (overwrite) |
| `!로어` + 텍스트 + 파일 | 텍스트+파일 합쳐서 **덮어쓰기** |
| `!로어` (인자 없음) | 현재 로어 상태 확인 |
| `!로어 초기화` | **전체 초기화** (NPC·장르·월드 전부 리셋) |

### 지원 파일

- 확장자: `.txt`, `.md`, `.json`, `.yaml`, `.yml`, `.log`, `.py`
- 최대 크기: 10MB / 100,000자
- 인코딩: UTF-8 자동 감지 (cp949/euc-kr 호환, 모지바케 자동 복구)

### 자동 추출 항목

로어를 넣으면 Flash가 자동으로 분석해서 아래를 추출합니다:

- **장르** — 3계층 (세계관/스타일/서사톤) + 분위기
- **PC 정보** — 이름, 종족, 외모, 배경, 비밀, 특질, 인벤토리
- **NPC 목록** — 이름, 성별, 종족, 역할, 위치, 설명
- **세계 요약** — 테마, 위치 목록, 팩션, 핵심 사건
- **세계 제약** — 마법/기술 체계(한계·비용 포함), 사회 구조, 금기
- **이상 징후 씨앗** — 서사 이벤트의 원천 (3~5개)
- **규칙** — 세계관 내 법칙/제한 (최대 10개)

> 형식에 구애받지 않습니다. 소설처럼 쭉 써도, 항목별로 정리해도 됩니다.

### 로어북 구조 권장 (선택)

헤더(`#`, `##`)로 나누면 RAG 검색 성능이 올라갑니다:

```markdown
# 세계관

중세 판타지 세계. 마법은 혈통으로 전승되며, 대가 없는 마법은 없다.
왕국은 3개 공작가가 분할 통치하고 있다.

## 마법 체계

혈통 마법: 가문마다 고유 속성. 남용 시 수명 단축.
계약 마법: 정령과의 계약. 대가는 기억.

## 주요 세력

왕당파 — 현 왕가 지지. 보수적.
개혁파 — 마법 민주화 주장. 위험시됨.

## 핵심 사건

3년 전 "붉은 밤" — 왕자 암살 미수. 범인 미상.
```

### NPC를 로어에 포함하기

로어 안에 `## NPC이름` 헤더로 NPC 섹션을 넣으면 **자동 등록**됩니다:

```markdown
## 엘리자

종족: 하프엘프
역할: 궁정 마법사
소속: 왕당파

냉정하고 과묵하다. 3년 전 붉은 밤의 유일한 목격자이나
그날 밤의 기억 일부가 빠져있다. 본인은 이를 인지하고 있으나
의도적으로 회피한다.

말투가 건조하고 단문 위주. 감정을 드러내는 경우가 극히 드물다.
```

> **500자 이상**의 NPC 섹션은 Flash 요약 대신 **원문 그대로** 등록됩니다.
> 500자 미만이면 Flash가 한국어로 요약해서 등록합니다.

## 2. NPC 등록 (`!npc추가` / `!npc`)

### 명령어 목록

| 명령어 | 동작 |
|---|---|
| `!npc` | 전체 NPC 목록 |
| `!npc 이름` | 특정 NPC 상세 보기 |
| `!npc추가 [내용]` | NPC 등록 (단일/일괄) |
| `!npc추가` + 파일 첨부 | 파일에서 일괄 등록 |
| `!npc 삭제 이름` | NPC 삭제 |
| `!npc voicecard 이름` | 보이스카드 재추출 |
| `!npc voicecard` | 전체 보이스카드 일괄 추출 |

### 입력 형식 3종 (자동 감지)

#### 형식 A: 마크다운 헤더 (권장)

`##`(H2)로 NPC를 구분합니다. 가장 정확합니다.

```markdown
## 카를로스

종족: 인간
역할: 용병단장

거친 외모와 달리 세심하다. 부하들에게는 엄격하지만
부상병을 직접 치료할 정도로 세심한 면이 있다.
"검은 네가 쥔다. 방패는 내가 든다." 가 입버릇.

## 리나

종족: 드워프
역할: 대장장이

과묵하고 완고하다. 자신이 만든 무기에 이름을 붙이는 습관.
주문 제작만 받으며, 재료를 고객이 가져와야 한다.
```

> `###`(H3)은 NPC 구분선이 아닙니다 — 같은 NPC 내부 소제목으로 취급됩니다.

#### 형식 B: 이름 선언

`[NPC NAME]:`, `Name:`, `이름:` 등으로 시작합니다.

```
이름: 카를로스
종족: 인간. 용병단장.
거친 외모와 달리 세심하다.
====
이름: 리나
드워프 대장장이. 과묵하고 완고하다.
```

> `===` 또는 `---` (3자 이상)는 구분선으로 자동 무시됩니다.

#### 형식 C: 간단 형식

`이름: 설명` 한 줄씩.

```
카를로스: 인간 용병단장. 거친 외모와 달리 세심하다.
리나: 드워프 대장장이. 과묵하고 완고하다.
```

> 콜론(`:`) 없는 줄은 바로 위 NPC의 설명에 이어붙습니다.

### 자동 추출 필드

설명이 200자 이상이면 아래 필드가 자동 추출됩니다:

| 필드 | 추출 패턴 |
|---|---|
| `role` | `Rank/Role:` 또는 `Occupation:` |
| `location` | `Occupation:` / `Affiliation:` 내 위치 키워드 |
| `tone` | `Tone:` |
| `personality` | `### Core Operating Principle` 다음 첫 줄 |
| `constraints` | `CANNOT`, `NEVER`, `MUST NOT` 포함 문장 (최대 3개) |

> 이 필드들은 자동 추출 보너스입니다. 없어도 설명만으로 충분히 작동합니다.

### 보이스카드 (자동)

설명이 **300자 이상**이면 보이스카드가 자동 추출됩니다:
- Tone (말투)
- Quirks (버릇)
- Shifts (감정 변화 시 말투 변화)
- Catch (시그니처 표현)
- Sample (예시 대사)

## 3. 작성 팁

### 좋은 NPC 프로필의 요소

```markdown
## 마르셀

종족: 인간
역할: 이발사 겸 정보상

마른 체격에 항상 깔끔한 셔츠. 면도칼을 손에서 놓지 않는다.
가게에 들어오는 사람의 신발을 먼저 본다.

말이 많지만 정작 자기 이야기는 하지 않는다.
질문에 질문으로 답하는 버릇. "그건 왜 궁금하신 건데요?"

비밀: 3년 전 붉은 밤에 왕자의 호위를 매수한 중개인.
본인은 죄책감을 느끼지만, 동시에 그 돈으로 동생의 병원비를 냈다.
```

**포함하면 좋은 것:**
- 외모 (시각적 디테일 1~2개)
- 행동 패턴 / 습관 / 버릇
- 말투 특징 (짧은 예시 대사 포함 시 보이스카드 품질 향상)
- 비밀 / 숨긴 동기 (있으면)
- 다른 NPC와의 관계

**불필요한 것:**
- MBTI, 혈액형 등 추상 분류
- "성격: 밝고 활발하다" 같은 형용사 나열
- 게임 스탯 (HP, ATK 등)

### 좋은 로어의 요소

**마법/기술 체계를 쓸 때:**
```
혈통 마법은 가문의 피에 새겨진 속성을 끌어쓴다.
대가: 사용할수록 수명이 줄어든다. 과용 시 백발화.
한계: 속성은 하나뿐이며, 바꿀 수 없다.
```
→ 한계와 대가를 명시하면 AI가 "만능 해결" 서사를 피합니다.

**세력/팩션을 쓸 때:**
```
개혁파 — 마법 민주화를 주장. 평민 마법사들이 주축.
왕당파 — 혈통 마법의 순수성 고수. 3대 공작가 연합.
→ 두 세력은 표면적으로 평화 공존하나, 암살과 회유가 오간다.
```
→ 세력 간 긴장 관계를 명시하면 서사 이벤트가 풍부해집니다.

## 4. 주의사항

| 함정 | 설명 |
|---|---|
| `!로어 초기화`는 전체 리셋 | 로어만이 아니라 NPC·장르·월드 상태 전부 날아감 |
| 파일 첨부 = 덮어쓰기 | 기존 로어가 교체됨. 추가하려면 텍스트만 입력 |
| `!npc` 단일 등록 시 콜론 필수 | `!npc추가 Alice` → 실패. `!npc추가 Alice: 설명` → 성공 |
| `##`만 NPC 구분 | `#`(H1)이나 `###`(H3)은 구분선으로 인식 안 됨 |
| 수동 등록 > 로어 추출 | `!npc추가`로 등록한 NPC는 로어 재업로드 시 덮어써지지 않음 |
| 보이스카드는 300자 이상만 | 짧은 설명에는 보이스카드가 생성되지 않음 |
